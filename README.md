# Health Tracker Website (PHP Native)

## Struktur Folder
- `config/` → konfigurasi database
- `includes/` → helper (cek login)
- `controllers/` → proses login/register/input data
- `views/` → halaman tampilan (UI)
- `assets/` → css, js, gambar

## Cara Menjalankan
1. Letakkan folder `health-tracker` di `htdocs/` (XAMPP).
2. Import `health_tracker.sql` ke phpMyAdmin.
3. Jalankan di browser: `http://localhost/health-tracker/`
4. Register akun baru → login → input aktivitas → lihat dashboard.

## Teknologi
- PHP Native
- MySQL
- Chart.js
- HTML/CSS
